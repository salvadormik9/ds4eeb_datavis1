## Learning Outcomes 
1. Understand the difference between hex codes and RGB
2. Import and apply different colors and color palettes in R
3. Recognize how color choices affect data interpretation
4. Carefully colors to make plots more accessible


## Activity: Using Color in R
To download the .R file, click on `datavis1_activity.R`. This will bring you to a new page. 
Near the top right, click the Download button. It looks like a downward arrow.

<img width="584" height="166" alt="DownloadingRfiles" src="https://github.com/user-attachments/assets/01f55475-f532-400b-96f6-06ad8c38140c" />

Once downloaded to your computer, you can now open `datavis1_activity.R` in RStudio! This activity should take ~ 15 minutes.
